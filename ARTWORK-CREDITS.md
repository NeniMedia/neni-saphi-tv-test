# Local preview artwork

The UI preview includes three locally stored 500px vintage movie-poster images. Their Commons file records document public-domain status. No production media, artwork, account or API access is needed. Runtime image requests go only to the local preview server. The original purple geometric sample art remains the fallback and is retained for the other library fixtures.

These are visual test fixtures. Their playback is the generated H.264/AAC test clip, **not the named feature film**. The sample description and Preview labels disclose this. Repetition lets the small sample collection exercise off-screen poster navigation and pagination. The machine-readable source inventory is `reports/artwork-sources.json`.
